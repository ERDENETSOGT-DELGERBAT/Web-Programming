Frequently Asked Questions

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

What is semantic HTML?

Semantic HTML uses elements based on their meaning. It makes the structure of a page easier to understand.

Why is the alt attribute important?

The alt attribute gives text information about an image. It is also useful when an image cannot load.

What does DOCTYPE do?

The DOCTYPE tells the browser that the document uses HTML. It helps the browser display the page correctly.
