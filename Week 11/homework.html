WEEK 11 · HOMEWORK

React Portfolio Gallery

This homework applies React components, props and state to create a personal portfolio gallery. Project data is organized separately and displayed using reusable cards.

Project Overview

The portfolio presents selected Web Programming coursework and a collaborative project. It uses reusable React components to display project information consistently.

Featured Projects

01 — Book Search

A book search website using the Open Library API.

02 — Student Registration

A registration page with form inputs and validation.

03 — What's Cooking?

A collaborative recipe website with search and favourites.

Main Features

  • Reusable ProjectCard components.
  • Project information stored in a separate data file.
  • ProjectList component for rendering the gallery.
  • Technology filters using React state.
  • Dark mode and light mode.
  • Responsive layout for different screen sizes.
  • GitHub Pages deployment.
