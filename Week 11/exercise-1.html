Profile Card Component

This exercise demonstrates how to create a reusable React profile component and pass information into it using props.

Objective

Create a profile card that displays a person's name, role and email address. The component receives its information from its parent component through props.

Implementation

The ProfileCard component is imported into App.jsx and rendered with the professor's information.
