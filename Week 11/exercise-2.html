WEEK 11 · EXERCISE 02

Notification List

This exercise demonstrates conditional rendering in React by displaying notification messages through a reusable NotificationList component.

Objective

Display a list of notification messages in the application. The component demonstrates how React can decide what to display based on the available notification data.

Displayed Notifications

  • Profile updated successfully
  • Password expires in 3 days
  • New lecture materials available

Implementation

Component

NotificationList.jsx

Concept

Conditional rendering

Skills Practised

  • Creating a separate React component.
  • Displaying multiple notification messages.
  • Using conditional rendering to control displayed content.
  • Organizing interface elements into reusable components.
