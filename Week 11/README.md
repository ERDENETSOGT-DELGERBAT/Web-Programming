# Week 11 – React Components and Props

## Overview

This week focused on React components, props, reusable UI elements, conditional rendering, and rendering lists.

## 1. Practice Exercises

**Repository:** [Task 11](https://github.com/ERDENETSOGT-DELGERBAT/task11)

**Live Website:** [Student Directory](https://erdenetsogt-delgerbat.github.io/task11/)

The practice exercises include:

- Student Profile Card components using props.
- Profile Card component.
- Conditional notification rendering.
- Reusable Card component using the `children` prop.
- Course Catalog with reusable course cards and conditional badges.

## 2. React Portfolio Gallery

**Repository:** [Portfolio](https://github.com/ERDENETSOGT-DELGERBAT/portfolio)

**Live Website:** [Personal Portfolio](https://erdenetsogt-delgerbat.github.io/portfolio/)

The portfolio gallery was developed using React and reusable components.

Features include:

- Reusable project cards.
- Project data stored separately.
- Technology-based project filtering.
- Dark mode.
- Responsive layout.
- GitHub Pages deployment.

## 3. Technologies Used

- React
- JavaScript (JSX)
- HTML
- CSS
- Vite
- GitHub and GitHub Pages

## 4. Learning Outcomes

Through these exercises, I practised creating reusable React components, passing data through props, using the `children` prop, rendering lists, implementing conditional rendering, and managing component state.
