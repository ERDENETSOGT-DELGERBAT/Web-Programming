React useState Cheat Sheet

Quick examples for the Week 12 React State exercises.

Basic syntax

const [val, setVal] = useState(initialValue);

Update a primitive value

setCount(count + 1);
// Or use a functional update:
setCount(previous => previous + 1);

Update an object

setUser(previous => ({
  ...previous,
  age: 21
}));

Add to an array

setItems(previous => [...previous, newItem]);

Remove from an array

setItems(previous =>
  previous.filter(item => item.id !== id)
);

Toggle a boolean

setIsOpen(previous => !previous);

Rules of Hooks

Call Hooks at the top level of React function components or custom Hooks. Do not call them inside loops, conditions, or nested functions.

Lifting state up

When multiple child components need the same state, move that state to their closest common parent. The parent passes values and update functions to the children through props.
